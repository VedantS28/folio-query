How Folio works

Follow your files from upload to a sourced answer.

  1. Extract the file

    Folio’s Java backend reads text, pages, and spreadsheet rows. The workspace keeps extracted content in browser memory.

  2. Select the evidence

    Folio uses keyword and semantic search to find relevant passages. Short files can fit in full. Longer summaries use samples from across the file.

    Spreadsheet calculation

    For supported calculations, Java works directly from workbook rows and returns the result without sending them to Groq.

  3. Mask detected identifiers

    Before calling Groq, the backend replaces filenames and detected identifiers in the evidence, question, and follow-up context with temporary placeholders.

    maya@example.com → FOLIO_…_END

  4. Generate the answer with Groq

    Groq receives the masked prompt and writes an answer using numbered source passages.

  5. Restore values and show sources

    Folio restores recognized placeholders on the backend and displays the answer alongside its source excerpts. It discards the mapping after the request.

What masking can miss

Detection is best effort. Names without labels, unusual identifiers, and confidential facts in ordinary prose can still reach Groq. Source excerpts shown in your workspace contain the original text.
